# facebook-comments-downloader
## How to Run

1. Open `main.py` and fill in:
   - `page_id`
   - `post_id`
   - `access_token`

2. Create a virtual environment:
```
   python -m venv venv
```

3. Activate it (Windows):
```
   .\venv\Scripts\activate
```

4. Install dependencies:
```
   pip install -r requirements.txt
```

5. Run the program:
```
   python .\main.py
```
